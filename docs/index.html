Chi tiêu, lịch, nhiệm vụ, sức khỏe, giấy tờ, đi chợ, điểm thưởng cho trẻ và trợ lý AI. Tự host trên một chiếc máy nhỏ đặt góc nhà — dữ liệu riêng tư tuyệt đối, không gửi lên cloud của ai.

Vì sao tự host tại nhà?

Đây không phải dịch vụ đám mây thuê bao. Nó chạy trên phần cứng của chính bạn.

🔒

Riêng tư tuyệt đối

Tài chính, sức khỏe, giấy tờ… nằm trên ổ đĩa nhà bạn. Không bên thứ ba nào đọc được.

💸

Không phí hàng tháng

Mua máy một lần. Tiền điện mỗi tháng chỉ vài nghìn đồng cho cả gia đình dùng thoải mái.

🍓

Phần cứng nhỏ gọn

Raspberry Pi 5, mini PC, NAS hay máy Linux cũ — cài Docker là chạy 24/7, êm và mát.

📶

Dùng mọi lúc mọi nơi

Ở nhà qua Wi-Fi; ra ngoài vào an toàn qua Tailscale — không cần mở port hay IP tĩnh.

📱

Như app thật

Cài lên màn hình chính iPhone/Android (PWA), có thông báo đẩy, chạy toàn màn hình.

♻️

Tự cập nhật & sao lưu

Watchtower tự nâng cấp bản mới; backup mỗi đêm, gửi kèm ra Telegram để cất offsite.

📸 Ảnh màn hình

Giao diện Neumorphism, hỗ trợ Light / Dark mode. Bấm vào ảnh để phóng to.

🤝 Đóng góp bản dịch

Muốn thêm tiếng Nhật, Hàn, Pháp…? Chỉ cần 3 bước — không đụng tới code UI:

Copy file locale gốc
cp src/i18n/locales/vi.json src/i18n/locales/ja.json
Dịch phần value, giữ nguyên key.
Đăng ký vào src/i18n/index.ts
Import file JSON + thêm vào SUPPORTED_LANGUAGES và resources.
Gửi Pull Request
Bộ chọn ngôn ngữ trong Settings tự hiện tùy chọn mới — xong!

🚀 Cài đặt trong 3 bước

Trên Raspberry Pi hoặc bất kỳ máy Linux nào có Docker.

Cài Docker

curl -fsSL https://get.docker.com | sudo sh

Clone repo & tạo cấu hình

git clone …/Family-Organizer rồi cp .env.example .env

Khởi chạy

docker compose up -d → mở http://<ip-máy>:3001
